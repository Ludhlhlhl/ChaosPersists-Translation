# Chaos Persists 汉化包

> **版本适配**：Minecraft 1.20.1 | 模组版本 0.3+
                         1.12.2 | 模组版本 1.2.7
                         1.7.10 | 模组版本 20.3
> **汉化状态**：99% 完全覆盖

## 项目简介

本汉化资源包基于 **天蝎_心殇** 的早期汉化文本进行迭代与修缮，并参照 **MC百科** (https://www.mcmod.cn) 的译名库进行术语统一。  
在此基础之上，针对新版本新增的机器、物品及剧情文本，借助 **DeepSeek AI** 进行了语境分析与初稿翻译，最终由本人逐条润色校订

## ⚠️ 使用声明与鸣谢
1. **特别致谢**：本汉化能够问世，离不开 **天蝎_心殇** 前辈此前贡献的优质文本基础，在此致以诚挚敬意。
2. **数据来源**：译名参考大量依赖于 **MC百科** 开放的数据支持，感谢百科编辑者的辛勤维护。
3. **AI角色**：**DeepSeek AI** 在本项目中仅作为翻译辅助工具，最终文本的准确性及版权归本项目所有。

## 🔧 使用
- **安装方法**：放入 ''resourcepacks'' 文件夹并在游戏中加载即可。
